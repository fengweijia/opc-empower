# OPC赚钱军师 - 本地部署与测试指南

本文档旨在指导开发者或体验者如何在本地环境中快速启动并测试 OpcVip/opc-empower 赚钱军师项目（前端基于 Taro 的微信小程序，后端基于 Node.js Serverless 架构）。

## 📋 环境前置要求

在开始之前，请确保您的本地机器已安装以下工具：

1. **Node.js**: >= 18.0.0 (推荐使用 nvm 或 n 管理 Node 版本)
2. **包管理器**: npm (随 Node.js 安装) 或 yarn
3. **IDE**: 推荐使用 VS Code
4. **微信开发者工具**: 用于预览和调试微信小程序前端 ([下载地址](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html))
5. (可选) **Git**: 用于拉取和管理代码版本

## 🚀 步骤一：后端服务启动 (Backend)

后端服务负责 AI 代理调度、大模型 API 请求重试退避以及与飞书的数据交互。

1. **进入后端目录并安装依赖**
   ```bash
   cd /Users/apple/Documents/PythonP/OpcVip/opc-empower/backend
   npm install
   ```

2. **启动本地测试服务器**
   由于我们刚刚清理了旧的测试脚本，你可以使用 Node 直接运行主入口：
   ```bash
   # 若 index.js 内部有模拟的 HTTP server 监听代码：
   node index.js
   ```
   > 💡 **注意**：如果 `index.js` 是纯 Serverless handler 导出而没有挂载 `http` 服务，你可以使用框架自带的本地模拟工具，或通过我们编写的临时调用脚本进行测试。
   > **关于环境变量**：目前本项目设计为 **"无环境依赖(Zero-env)"**，所有核心配置（飞书 Token、AI API Key 等）均由前端小程序的用户设置页动态传入，后端 `backend` 目录下无需配置任何 `.env` 文件即可启动。

## 📱 步骤二：前端小程序启动 (Frontend)

前端基于 Taro 4.0 + React 18，目前主要目标平台为微信小程序。

1. **进入前端目录并安装依赖**
   ```bash
   cd /Users/apple/Documents/PythonP/OpcVip/opc-empower/frontend
   npm install
   ```

2. **启动微信小程序本地编译**
   执行以下命令，Taro 会监听文件修改并实时编译到 `frontend/dist` 目录：
   ```bash
   npm run dev:weapp
   ```

3. **使用微信开发者工具预览**
   - 打开 **微信开发者工具**。
   - 选择 **“导入项目”**。
   - 目录选择：`/Users/apple/Documents/PythonP/OpcVip/opc-empower/frontend` （或者选择编译产出的 `dist` 目录，具体视 Taro 配置而定，一般选项目根目录即可识别 `project.config.json`）。
   - AppID：如果你有自己的小程序 AppID 可以填入，否则选择 **“测试号”**。
   - 点击“确定”后，你就可以在开发者工具的模拟器中看到 “OPC赚钱军师” 的 UI 界面了。

## ⚙️ 步骤三：应用内配置与联调 (核心闭环体验)

启动成功后，为了让 AI 代理和飞书存储正常工作，你需要在小程序 UI 内进行配置：

### 1. 配置 AI 模型 (必填)
1. 在小程序中，点击底部导航进入 **“我的 (Profile)”** 或直接进入 **“设置 (Settings)”** 页面。
2. 找到 **AI 模型配置** 区域。
3. 选择你想用的提供商（如：`SiliconFlow`、`DeepSeek`、`OpenAI`）。
4. 填入你申请到的 **API Key**（比如从硅基流动官网获取的 Key）。
5. 保存配置。

### 2. 配置个人档案 (必填)
为了让“定位诊断”和“7天发售”能生成专属内容：
1. 在设置或档案页，填写 **“我要卖的产品/服务”**（例如：*Python自动化提效工具*）。
2. 填写 **“目标客户”**（例如：*每天被重复工作折磨的初级运营*）。

### 3. 配置飞书多维表格 (可选)
如果你希望沉淀历史生成记录、Prompt 版本等：
1. 按照 `README.md` 中的说明，在飞书开放平台获取 `App ID` 和 `App Secret`。
2. 在小程序设置页填入上述信息以及你的飞书多维表格的 Token 和 Table ID。

## 🧪 步骤四：功能测试验证

现在你可以开始验证我们 MVP (v1.0) 的核心闭环了：

1. **测试定位诊断 (雷达图与30天路径)**
   - 回到小程序首页，点击 **“赚钱策略”**。
   - 选择 **“定位诊断”**。
   - 观察是否出现了平滑的 **Loading 跑马灯骨架屏**。
   - 生成完毕后，检查页面是否正确渲染了 **雷达图数据** 以及纵向的 **“地铁线路图”时间轴**。

2. **测试发售脚本 (横向Tab与手机壳UI)**
   - 点击 **“赚钱流程”**。
   - 选择 **“7天发售加速器”**。
   - 生成完毕后，检查是否出现了 **Day 1 到 Day 7 的横向滑动 Tab**。
   - 检查下方是否出现了类似手机壳的 **预览框**，并包含朋友圈文案、私聊气泡以及 **[一键复制]** 按钮。

3. **测试容错与异常拦截**
   - 故意将设置里的 API Key 改错。
   - 再次请求生成，观察是否弹出了温和的 **Error 错误提示组件**（提示“军师的大脑走神了...”）而不是直接白屏崩溃。
