## 三、后端部署

### 3.1 安装依赖

```bash
cd backend

# 安装Node.js依赖
npm install

# 安装可能需要的全局工具
npm install -g nodemon
```

### 3.2 配置环境变量

```bash
# 创建环境变量文件
cp .env.example .env

# 编辑配置（可选，有默认Mock数据）
nano .env
```

**.env 文件内容参考**：
```bash
# 飞书配置（可选，当前可用Mock数据）
LARK_APP_ID=your_app_id
LARK_APP_SECRET=your_app_secret

# AI配置（可选，当前可用Mock数据）
AI_PROVIDER=openai  # 或 deepseek/claude
AI_API_KEY=your_api_key
AI_API_ENDPOINT=https://api.openai.com/v1

# 服务端口
PORT=3000
```

### 3.3 测试后端服务

```bash
# 方式1：直接运行
cd backend
node index.js

# 方式2：使用nodemon热重载（推荐开发）
nodemon index.js
```

**预期输出**：
```
🚀 Serverless 服务已启动: http://localhost:3000
✅ 健康检查: http://localhost:3000/
```

### 3.4 测试API

```bash
# 新开终端，测试健康检查
curl -X POST http://localhost:3000/ \
  -H "Content-Type: application/json" \
  -d '{"action":"health"}'

# 预期返回：
# {"success":true,"message":"OK","data":{"status":"healthy"...}}
```

```bash
# 测试获取Agent列表
curl -X POST http://localhost:3000/ \
  -H "Content-Type: application/json" \
  -d '{"action":"getAgents"}'

# 预期返回4个Agent的列表
```

## 六、常见问题

### Q1: npm install 报错

```bash
# 清理缓存后重试
rm -rf node_modules package-lock.json
npm install
```

### Q2: 端口被占用

```bash
# 查找占用端口的进程
lsof -i :3000

# 杀掉进程
kill -9 <PID>

# 或者换端口
PORT=3001 node index.js
```

### Q3: 微信开发者工具无法预览

1. 确保已安装稳定版微信开发者工具
2. 确保已用微信号登录
3. 尝试重启开发者工具

### Q4: AI API 调用失败

当前版本使用Mock数据，不需要真实API。
如需测试真实API，在`.env`中配置AI Key即可。
