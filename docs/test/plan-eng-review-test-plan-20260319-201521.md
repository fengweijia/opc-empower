## Affected Pages/Routes
- 小程序「设置/配置」页 — 验证 AI 配置、飞书配置能保存且不泄露密钥
- action=testAI — 验证各 provider 连通性与错误提示
- action=testLark — 验证飞书连通性与权限错误提示
- action=executeAgent（strategy/positioning）— 验证定位诊断输出结构化 JSON
- action=executeAgent（strategy/*）— 验证 30 天路径类输出结构化 JSON
- action=executeAgent（process/launch_script）— 验证 7 天发售素材包输出结构化 JSON
- 历史记录页（action=getHistory）— 验证按 userId 查询、筛选与渲染
- 反馈入口（评分/改进标签）— 验证反馈写入飞书并可回溯到对应生成记录

## Key Interactions to Verify
- 完整闭环：填写档案 → 生成「定位诊断」→ 生成「30天路径」→ 生成「7天发售」→ 点赞/差评+改进标签 → 历史可见
- 错误路径：API Key 缺失/无效、模型ID错误、API端点错误、飞书权限不足、飞书表字段不匹配
- JSON 输出健壮性：模型返回 code fence、前后有解释文本、字段顺序变化时，仍能解析并渲染

## Edge Cases
- 生成内容超长：响应被截断、max_tokens 不足、飞书字段写入超限
- LLM 超时/429：重试策略生效，前端显示可理解的错误而非“空白”
- 并发点击：重复提交导致重复记录/错位（生成记录与反馈关联）
- 缓存一致性：prompt/knowledge 版本切换后，新请求使用新版本，旧记录仍可回放

## Critical Paths
- P0：executeAgent 主流程可用且返回可渲染的结构化数据
- P0：飞书写入失败不影响生成返回（但会给出明确告警/降级提示）
- P1：反馈数据能关联到 prompt_version / playbook_version（用于进化系统）
